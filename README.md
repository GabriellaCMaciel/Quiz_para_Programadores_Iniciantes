# Quiz para Programadores Iniciantes

Página de quiz sobre conceitos básicos de programação e desenvolvimento web. Foi um dos meus primeiros projetos (janeiro de 2025), feito para praticar **formulários em HTML** e estilização com CSS.

## O que tem no quiz

São 8 perguntas, cada uma usando um tipo diferente de campo de formulário:

| Pergunta | Campo usado |
| --- | --- |
| Linguagem que estrutura páginas web | botões de opção (`radio`) |
| O que é "google.com" numa URL | texto |
| Exemplo de senha forte | senha (`password`) |
| Ano da primeira versão do HTML | data (`date`) |
| Quais são linguagens de programação | caixas de seleção (`checkbox`) |
| Upload de um arquivo com código HTML | arquivo (`file`) |
| Atributo que define o tipo do input | lista de opções (`select`) |
| Linguagem do logotipo | imagem + texto |

No fim da página há uma tabela de pontuação, um gabarito que abre e fecha (`details`) e um formulário de feedback com e-mail e comentário.

## Tecnologias

- HTML5
- CSS3

## Como rodar

Baixe o repositório e abra o `index.html` no navegador.

## O que eu aprendi

- Os principais tipos de `input` e quando usar cada um
- Como montar formulários, tabelas e conteúdo que expande com `details`
- Como ligar duas páginas (`index.html` e `sobremim.html`)
